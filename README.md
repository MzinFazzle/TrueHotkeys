# True Hotkeys (v1.2.0)

An SKSE plugin that turns your keyboard into a real hotkey system for
weapons, spells, shouts, outfits, and more. Configured entirely in-game.
No INI editing required.

## Build requirements

- **CMake 3.21+**
- **[vcpkg](https://github.com/microsoft/vcpkg)**:
  1. Clone it: `git clone https://github.com/microsoft/vcpkg`
  2. Bootstrap it: run `bootstrap-vcpkg.bat` inside that folder
  3. Set a `VCPKG_ROOT` environment variable pointing at that folder
